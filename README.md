# 🎮 Gspace

> **The first Super App built for Persian-speaking gamers.**

Gspace is an all-in-one platform designed for Persian-speaking gamers, bringing together **gaming news, chat rooms, social features, game information, and more** in one place.

## ✨ Features

* 📰 **Gaming News** — Stay up to date with the latest gaming news and events.
* 💬 **Chat Rooms** — Connect and chat with other gamers.
* 🌐 **Social Space** — A dedicated social environment for the gaming community.
* 🎮 **Game Information** — Explore information and details about different games.
* 🚀 **And More** — New features are continuously being developed.
